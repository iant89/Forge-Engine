Generated by `tools/gen-gltf-material-features.py` for Forge Engine (Phase 16.1c). Licence: CC0 1.0.

Four quads, one per glTF material feature: emissive texture, occlusion texture, alpha MASK
(doubleSided) and a CLAMP_TO_EDGE + NEAREST sampler on a UV 0..3 quad. Used by
`tests/resources/gltfTextures.test.ts` and `?scene=gltf-skin&model=features` (browser gate).
