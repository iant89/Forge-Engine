  (https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/SimpleSkin), fetched 2026-10-13, unmodified.

  credited here anyway.
- Content: a 1 × 2 m strip (10 vertices, 8 triangles, positions only) skinned to two joints, with one
  LINEAR rotation animation on the upper joint. It is explained in the glTF tutorial's skinning chapter
  (https://github.com/javagl/glTF-Tutorials/blob/master/gltfTutorial/gltfTutorial_019_SimpleSkin.md).
- Used by: `examples/src/scenes/gltfSkinScene.ts` (`?scene=gltf-skin`), `tests/resources/gltfScene.test.ts`
  and `npm run check:browser:gltf-skin`.
